# Encontrar el proyecto adecuado

Este repositorio contiene el perfil que aparece en GitHub. Su trabajo es ayudarte a elegir un proyecto y llegar a su guía. No contiene una aplicación compartida ni necesita una instalación.

## Cómo se organiza

`README.md` es la portada. Cada enlace lleva a un repositorio independiente donde están su instalación, manual, código y comprobaciones. No se copian aquí las versiones o los resultados de las pruebas porque cambian en cada proyecto.

| Repositorio | Pregunta que responde su portada |
| --- | --- |
| `calcx-advanced` | ¿Cómo resuelvo esta cuenta? |
| `nexus-intelligence` | ¿Qué puedo observar de mi dominio? |
| `threat-detection-suite` | ¿Cómo leo la actividad recogida de Windows? |
| `Aegis11` | ¿Qué ajustes cambiarán y cómo los recupero? |
| `Project-MegaTicketing` | ¿Cómo elijo y solicito un asiento? |

## Mantener los enlaces útiles

Cuando cambie una función, actualiza primero la guía del proyecto que la implementa. Cambia este perfil si eso modifica la tarea que puede resolver una persona. Una compilación correcta y una instalación pública son cosas distintas; el perfil no debe prometer la segunda basándose solo en la primera.
